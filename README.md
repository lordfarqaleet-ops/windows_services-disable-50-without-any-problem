Windows Services Optimizer
A PowerShell script that safely disables 50+ unnecessary Windows background services to improve system performance, reduce RAM usage, and speed up boot times — without breaking your system.
What it does:

Disables bloat and telemetry services (diagnostics, tracking, reporting)
Turns off services irrelevant to most desktop/gaming setups (fax, remote registry, tablet input, etc.)
Backs up current service states before making any changes so you can restore anytime
Logs every change with before/after status
Skips critical system services automatically — nothing that breaks Windows

Who is it for:
Enthusiasts, gamers, and power users who want a leaner Windows install without manually hunting through services.msc one by one.
